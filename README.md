# TAMORU

Static frontend built with HTML, CSS and JavaScript.

## Run locally

Open `index.html`, or run `python -m http.server 8000` and visit http://localhost:8000.

## Current version

- Preserves the original page content, section order and pet generator.
- Uses TAMORU branding and the supplied logo.
- Uses the #B1D360 page background.
- Contract address: TBA. Address copying is disabled until an address is configured.

No build step or package installation is required.
